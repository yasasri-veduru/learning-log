IOT · EMBEDDED PROTOTYPE IN PROGRESS

ESP32 Battery Health Management System

An IoT system that tracks battery usage to estimate remaining battery life and monitors temperature, raising an alert when it goes above a set threshold. The design was built and tested in the Wokwi simulator, and I am now wiring the physical prototype around a real 3.7V Li-ion battery.

  • ESP32
  • INA219 current/voltage sensor
  • DHT11 temperature sensor
  • TP4056 charging module
  • Relay module
